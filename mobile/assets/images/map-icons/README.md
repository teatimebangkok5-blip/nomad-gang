Map place icons (one per place type, see `PLACE_ICON_COLORS` in `src/lib/places.ts`): a 3D glossy colored ball
with a white rim, shine and shadow and a white icon, 120 × 120 px. The icons inside are Google's Material Icons (Apache License 2.0,
https://github.com/google/material-design-icons). Generated with a System.Drawing script on Windows (`cowork.png` was drawn to match with sharp from an SVG); to add a type, draw
a matching PNG and register it in `PLACE_ICON_IMAGES` in `src/components/venue-map.tsx`.
